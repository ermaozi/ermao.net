## 上线后评估方案

1. 经用户单独批准，先部署同仓库第一方 Worker 的事件 schema/API，再发布静态站点；检查受保护统计入口与事件写入状态。
2. 用户提供 GSC 的页面、日期、国家/地区、设备维度导出。比较上线前 28 天与上线后完整 28 天，标注发布当天、算法变化及其他内容更新；小样本延长观察。
3. 搜索指标记录 impressions、clicks、CTR、position 的真实值与数据来源。没有数据的格子写“缺失”，不填 0。
4. 第一方聚合事件衡量进入评测/教程/排错和对比的点击次数；计数不是独立人数或转化率。重复点击节流、机器人及拦截可能影响计数。旧 PV 合并中英文路径，不直接用作中文 CTA 转化率分母。
5. 没有改善时先观察筛选空结果、错误与资料覆盖，再决定调整或回退；不能从单次前后对比推断因果。
