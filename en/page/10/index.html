Search engines such as FOFA and Shodan can reveal Ollama servers that have been exposed to the public internet. This page explains how to use that information for a defensive audit of systems you own or are explicitly authorized to test.

Ollama is a runtime for running and serving models; it is not itself a language model. Its API can serve DeepSeek and many other compatible models. According to the official Ollama FAQ, Ollama binds to 127.0.0.1:11434 by default. A publicly reachable instance therefore normally reflects an intentional configuration change, a container port mapping, a reverse proxy, or another network-exposure decision.
