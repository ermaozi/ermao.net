## Provider-stated features

The source lists:

* Windows, iOS, macOS, and Android clients;
* one-click connection and remote technical assistance;
* Trojan protocol subscriptions;
* an Emby media library; and
* a purported no-login Netflix access benefit.

Treat the bandwidth, availability, dedicated-route, and streaming statements as provider or source claims. A no-login streaming arrangement can disappear, expose a shared account, or conflict with the streaming service's rules.

The original page advertised a Mid-Autumn/Qixi promotion using code `koodog.com` through September 15. Because the article was created in August 2025, that promotion is historical and should not be assumed active.
