# Chinese-English terminology

Use these terms consistently unless a quoted official name requires otherwise.

| Chinese | Preferred English | Notes |
|---|---|---|
| 二毛 | Ermao | Brand and author name |
| 机场 | proxy service / proxy provider | Explain the Chinese slang “airport” only when the term itself is discussed |
| 机场推荐 | proxy-service reviews / recommended proxy services | Choose according to context |
| 翻墙 | censorship circumvention / bypass internet censorship | Avoid the literal “climb the wall” |
| 科学上网 | censorship circumvention / open-internet access | Do not translate literally |
| 节点 | proxy server / node | “Server” is clearer for general readers; retain “node” in client UI terminology |
| 线路 | route | Use “network route” when ambiguity is possible |
| 专线 | dedicated route | Do not imply a technically verified private circuit unless the evidence supports it |
| 中转 | relay route / relayed connection |  |
| 直连 | direct connection |  |
| 晚高峰 | evening peak hours | Preserve a stated local time window |
| 流媒体解锁 | streaming-service unblocking | State that results are time- and IP-sensitive |
| 解锁 | unblock / access | Choose according to the named service |
| 订阅 | subscription / subscription profile | “Profile” is often clearer for a client configuration URL |
| 订阅链接 | subscription URL | Never expose or alter a real credential-bearing URL |
| 通用订阅 | universal subscription format |  |

| 不限时 | no expiry | Distinct from unlimited data |
| 不限量 | unlimited data | Preserve fair-use qualifications |
| 不限速 | no advertised speed cap | Attribute to the provider unless independently tested |
| 一键导入 | one-click import |  |
