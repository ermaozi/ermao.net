## What is needed to open YouTube

Where lawful and authorized, a user generally needs:

1. a maintained client that supports the chosen VPN or proxy protocol;
2. a trusted server or subscription compatible with that client.

A client is not the network service itself. A subscription URL is a credential and should not be posted publicly.

Review current options in the [proxy-service index](/en/posts/vpn/) and verify operator identity, plan terms, client compatibility, and local law before paying.

## Desktop: Windows, Linux, and macOS

The Chinese source uses Clash Verge Rev:

1. obtain a compatible subscription through a verified provider;
2. install Clash Verge Rev from a trusted release source;
3. add the subscription URL under profiles or subscriptions;
4. select rule mode if the profile is designed for it;
5. enable the required system-proxy or TUN mode;
6. verify the route, DNS, and public IP before opening YouTube.

See the [Clash Verge installation and subscription guide](/en/article/0gematwc/) and the broader [desktop access guide](/en/blog/how-to-vpn-on-computer/).

The source offered mirrored executable and DMG files. A mirror can become stale or compromised, so prefer the project's authenticated official release and verify signatures or hashes where published.

## Android

The source uses a Clash Meta-compatible Android client:

1. install a maintained application from its official source;
2. choose the option to import a profile from a URL;
3. paste the private subscription URL;
4. inspect the profile and start the service;
5. approve the Android VPN request only for the intended application;
6. verify DNS and route behavior.

See the [Android Clash Meta guide](/en/article/eh8f4n86/) and [mobile access guide](/en/blog/how-to-vpn-on-mobile/).

## iPhone and iPad

The source uses Shadowrocket:

1. obtain the application through an App Store account you control where practical;
2. add a subscription from the provider's authenticated dashboard;
3. select a node and approve the iOS VPN configuration;
4. verify that the profile routes the expected traffic.

See the [Shadowrocket guide](/en/article/z747kgjd/).

The Chinese source promotes a shared United States Apple ID. Shared credentials can be revoked, expose account activity, trigger account locks, or create device-recovery risk. If one is used despite those risks, never sign it into iCloud or the device's main Settings account; the safer approach is an account the user owns. See the [shared Apple ID risk notes](/en/blog/freeappleid/).

## Frequently asked questions

### Is using a VPN or proxy legal?

There is no universal answer. The applicable law depends on jurisdiction, authorization, service, and use. The Chinese source's blanket statement that “using a VPN itself is not illegal” is too broad. Review the [legal and compliance overview](/en/blog/vpnhefa/) and obtain qualified local advice when necessary.

### Are free services safe?

Price does not determine safety. A free service may have severe congestion, uncertain funding, intrusive tracking, malicious software, or weak support. A paid service can also log traffic, disappear, or be compromised. Evaluate the operator, client provenance, protocol, policy, and evidence.

### Can one subscription be used on a phone and computer?

Only if the current plan permits those devices, concurrent IPs, and sharing pattern. Check the terms rather than assuming all providers allow it.

### What else can be reached?

Access depends on the network, exit region, account, and platform rules. A tunnel does not guarantee Google, AI, streaming, or social-platform access, and it does not bypass account-level restrictions.
