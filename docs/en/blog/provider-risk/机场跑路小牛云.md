From December 1, 2025, many Xiaoniu Cloud nodes failed and support became unreachable, while the website remained accessible and continued accepting purchases.

**Moderate-risk alert:** Exercise caution and avoid renewing until the problems are resolved and independently verified.

## Xiaoniu Cloud shutdown alert

::: caution

Multiple warning signs indicate that Xiaoniu Cloud may shut down in the near term.

Existing users should limit exposure and avoid renewing.

:::

**The source article also advises caution with the related Xiaoniu VPN product. The corporate relationship and its present condition were not independently verified for this translation.** [Search reference](https://cn.bing.com/search?q=%E5%B0%8F%E7%89%9BVPN)

Reported Telegram group: [https://t.me/aoxcloud](https://t.me/aoxcloud)

---

### October 2025: users began reporting unstable nodes

During this period, Xiaoniu Cloud support was reportedly still replying.

![October user report about unstable Xiaoniu Cloud nodes](https://image.ermao.net/images/scamvpn/xiaoniu/image-5.png)

### November 2025: more users reported nodes becoming unreachable

Support replies reportedly became much less frequent during November.

![November Xiaoniu Cloud outage report](https://image.ermao.net/images/scamvpn/xiaoniu/image-6.png)

![Additional November Xiaoniu Cloud outage report](https://image.ermao.net/images/scamvpn/xiaoniu/image-7.png)

### December 2025: support became unreachable

![Xiaoniu Cloud support-status evidence](https://image.ermao.net/images/scamvpn/xiaoniu/image.png)

Several discussion-group users reported that Xiaoniu Cloud support had not replied for a long time.

![Discussion-group report about unanswered support messages](https://image.ermao.net/images/scamvpn/xiaoniu/image-1.png)

The former support Telegram account had been deleted.

![Deleted former support account](https://image.ermao.net/images/scamvpn/xiaoniu/image-2.png)

The replacement support account had not replied for an extended period.

### Many subscription nodes became unreachable

![Many Xiaoniu Cloud subscription nodes offline](https://image.ermao.net/images/scamvpn/xiaoniu/image-4.png)

### Remaining nodes had poor performance

![Poor performance on remaining Xiaoniu Cloud nodes](https://image.ermao.net/images/scamvpn/xiaoniu/image-3.png)

At this point, Xiaoniu Cloud showed several common shutdown warning signs. Users should avoid renewing until verifiable service and support have returned.
