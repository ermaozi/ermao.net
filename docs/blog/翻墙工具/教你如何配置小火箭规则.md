## 什么是小火箭分流规则

流量去向取决于首页的**全局路由模式**及当前配置，不能只凭“有没有额外导入规则”判断。使用「配置」模式时，Shadowrocket 按配置分配流量；「代理」模式主要通过所选节点；「直连」模式不通过代理节点。

分流规则就像一个“交通信号灯”：

- **匹配直连规则的流量** → 直连，不经过代理节点
- **匹配代理规则的流量** → 使用相应节点或策略组
- **匹配拒绝规则的流量** → 拦截，但前提是配置确实包含这类规则

让国内服务直连可能减少绕路及代理流量消耗，实际效果取决于网络与命中的规则。没有导入某个规则文件不等于流量泄漏，也不能据此判定封号原因；分流规则不能保证账号安全或避免平台限制。

## 分流规则的匹配机制

规则顺序和类型都会影响匹配结果，可以先按“具体规则优先、`FINAL` 兜底”理解：

- 命中代理规则 → 使用该规则指定的节点或策略组
- 命中直连规则 → 直接连接
- 前面的规则没有命中 → 执行 `FINAL` 指定的默认策略

本文核对的懒人配置包含常用服务规则集、`GEOIP,CN,DIRECT`，最后是 **`FINAL,PROXY`**。因此未命中的请求默认走代理，并不是“默认直连的黑名单模式”。策略组的实际选择也会影响流量去向。

模块、域名类规则和 IP 类规则之间还有优先级区别；排查时应查看命中日志，而不是仅按规则数量判断效果。可参考[配置维护者的规则优先级说明](https://github.com/LOWERTOP/Shadowrocket#规则优先级)。

### 第一步：复制规则订阅地址

打开上面的 GitHub 项目页，向下滚动可以看到多种规则版本。

**需要常用服务分流和策略组，可以从懒人配置开始。** 如果主要需求是去广告，请先看下方的版本对比，选择上游明确标注“+ 去广告”的配置，不要把两者混为一谈。导入前先导出或复制当前配置，便于恢复。

复制下面这条地址备用：

```
https://johnshall.github.io/Shadowrocket-ADBlock-Rules-Forever/lazy_group.conf
```

### 第二步：在小火箭中导入规则

1. 打开 Shadowrocket，切换到底部第二个 Tab「**配置**」
2. 点击右上角的 **+** 号
3. 在弹出的输入框中粘贴刚才复制的地址
4. 点击「**下载**」，等待几秒即可完成

下载成功后，配置列表中会多出一个新文件。

### 第三步：启用并生效

点击刚下载的配置文件，选择「使用配置」，确认出现 ✓ 标记。回到首页，把**全局路由设为「配置」**，检查策略组中所选节点可用，再断开并重新连接。

随后分别访问一个国内服务和一个需要代理的服务，查看日志中的命中规则与策略，确认结果符合预期。仅看到 ✓ 标记不能替代验证；若有异常，可以切回之前保留的配置。

## 检查配置自动更新（别和节点订阅混淆）

远程配置文件、它引用的规则集，以及机场的节点订阅是不同的更新对象。上游每天构建，不等于手机里的副本一定已刷新。

根据[配置维护者的自动更新说明](https://github.com/LOWERTOP/Shadowrocket#自动更新)，在 Shadowrocket 设置中找到**配置**对应的自动后台更新及更新间隔；**订阅**对应的是服务器节点更新。具体入口以安装的 App 版本为准，不能只打开节点订阅更新就认为规则文件已更新。

自动更新受 iOS 后台刷新和 App 运行状态影响，不能保证固定时刻执行。启用前先保留当前配置：远程文件更新可能覆盖本地自定义修改。

手动刷新时也要区分两种操作：

- **更新配置**：用远程版本覆盖当前配置，同时刷新相关远程资源
- **使用配置 / 编译配置**：可刷新引用的规则集等资源，不等同于替换配置文件本身

更新后重新检查命中日志；若下载失败，先检查地址和网络，不要把旧文件仍可使用误当成更新成功。

## 配置分流规则前后效果对比

分流的收益需要按自己的网络和流量验证，不能用固定速度或节省比例承诺效果：

| 对比项 | 可能的变化 | 核对方式 |
|--------|-----------|-----------|
| 国内网站加载 | 直连可能减少代理绕路 | 查看命中策略，并在相同网络下比较加载情况 |
| 机场流量消耗 | 被分配为直连的流量不占用代理流量 | 结合 App 与服务商流量记录核对 |
| App 内广告 | 本文的懒人配置不提供已启用的广告拦截规则 | 如选择去广告版，逐个 App 检查效果及误拦截 |

广告是否能被拦截取决于所用规则及 App 的广告实现。拒绝规则不等于“一律在 DNS 阶段拦截”，也不能保证开屏、信息流或视频广告全部消失。

## 黑名单、白名单还是懒人配置？一张表看懂

规则库提供了多个版本，很多人不清楚该下载哪一个：

| 版本 | 工作方式 | 推荐场景 |
|------|---------|---------|
| **黑名单模式** | 默认走直连，只有列表内的被墙网站走代理 | 以访问国内网站为主，偶尔翻墙 |
| **白名单模式** | 默认走代理，只有列表内的国内网站走直连 | 重度海外用户，大部分时间浏览外网 |
| **懒人配置（含策略组）** | 常用服务分流，`FINAL,PROXY` 默认代理；未启用广告拦截规则 | 需要按服务选择节点的用户 |
| **明确标注“+ 去广告”的版本** | 在对应分流方式上加入广告过滤，具体以文件为准 | 需要广告过滤并愿意检查误拦截的用户 |

**先确定默认策略，再决定是否需要广告过滤。** 希望未命中请求直连时看黑名单版本；希望默认代理并按服务选节点时，可以从本文的懒人配置开始。需要去广告则查看上游单独提供的版本及说明。

高级用户如果有特殊需求（比如某些小众网站没有被规则覆盖），可以在懒人配置基础上手动添加自定义规则。

## 配完规则后，这 4 点也别忽视

规则解决的是流量分流问题，仍需检查实际效果，并遵守所用服务的平台规则。

### 1. 避免使用全局代理模式

「代理」模式会让通常由配置分流的请求经由所选节点，可能增加国内服务的绕路。实际位置与速度取决于节点；平台是否触发验证或限制由其自身规则决定，不能据此作出必然判断。

需要按本文配置分流时，使用**全局路由 → 配置**。如临时切换模式排查连接，完成后再检查是否已恢复。

### 2. 固定一个节点，别来回切换

频繁切换不同地区节点会改变服务看到的出口位置，可能触发额外验证，但是否受限还取决于账号行为和平台规则。规则文件本身不能消除这种不确定性。

建议选一个延迟低、线路稳定的节点长期使用。如果不确定哪家机场的节点质量好，可以参考 [2026 年机场推荐评测](/posts/vpn/)，里面有延迟和速度的真实测试数据。

### 3. 偶尔确认规则是否在正常更新

尽管设置了自动更新，也值得每隔一两周看一眼。

检查配置的更新记录及引用规则集是否成功刷新。如果长期没有变化，核对远程地址和更新结果；有本地修改时先备份，再决定是否用远程版本覆盖。一次手动更新并不保证能修复所有分流问题。

### 4. 新号期间控制操作频率

社交账号可能受到平台验证或行为限制。大量发帖、批量关注等操作可能违反平台规则，无论是否使用小火箭，都应先了解服务的使用要求。

遵守平台规则、保护账号登录凭据，并在出现限制时按平台指引申诉；分流配置不能代替这些措施。

## 零基础也能配：5 步速览

看到 GitHub、规则库、配置文件这些词就犯怵？别担心，你完全不需要理解什么是 IP-CIDR、RULE-SET 或者域名匹配。

实际操作只有 5 个动作：

1. 复制一条网址
2. 打开小火箭，粘贴进去
3. 点「下载」
4. 使用新配置，并把全局路由设为「配置」
5. 重连一次

完成后记得检查命中日志。下载与验证所需时间取决于网络和 App 版本，不需要为了赶时间跳过备份或核对。
