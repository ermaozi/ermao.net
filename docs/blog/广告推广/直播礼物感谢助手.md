直播时既要讲内容，又要盯礼物、记昵称并及时回复，很容易顾不过来。**直播礼物感谢助手**是一款运行在 Chrome、Edge 中的第三方浏览器插件，用来监听抖音网页直播间的礼物事件，并按预设规则发送感谢语。

从开发者提供的界面可以看到，它会统计礼物总计、礼物事件、已感谢和发送失败次数，还提供礼物列表浮窗、感谢规则、话术、日志与更新入口。它更适合礼物消息较多、需要减少重复操作的主播或场控人员。

## 安装教程

### 第一步：下载并解压插件

从开发者提供的正式页面下载压缩包。新建一个固定目录，例如 `D:\gift-thanks`，再把 ZIP 完整解压到该目录；不要直接在压缩包内打开，也不要安装后随意移动文件夹。

![插件下载页及开发者提供的四步安装说明 =1666x1083 =1666x1083](https://image.ermao.net/images/blog/douyin-live-gift-thanks-assistant/20260809_115928-33ceea.png)

下载后，建议先用系统安全软件扫描压缩包，并确认文件来源没有被替换。若浏览器或系统给出明确的恶意文件警告，应停止安装并向开发者核实。

### 第二步：在浏览器中加载扩展

1. Edge 打开 `edge://extensions`；Chrome 打开 `chrome://extensions`。
2. 开启页面中的“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择解压目录内的 `chrome-mv3` 文件夹。
4. 确认扩展列表中出现“抖音礼物感谢助手”，并保持启用。

![Edge 开发人员模式与加载解压缩扩展入口 =1666x1083 =1666x1083](https://image.ermao.net/images/blog/douyin-live-gift-thanks-assistant/20260809_115929-53a4c4.png)

### 第三步：注册本地辅助程序

在扩展管理页复制该扩展的 **ID**，然后双击解压目录中的 `install-host.bat`，按开发者页面提示粘贴 ID 并回车。完成后彻底退出浏览器，再重新打开。

`install-host.bat` 会在本机执行命令。看不懂脚本内容、文件来源不明，或脚本要求管理员权限却没有解释用途时，不要继续。

### 第四步：输入授权码

打开抖音网页直播间，点击浏览器工具栏中的扩展图标，按提示输入购买后获得的授权码。激活成功后，设置页会显示授权码的脱敏信息和有效期。

![直播礼物感谢助手授权激活状态 =991x670 =991x670](https://image.ermao.net/images/blog/douyin-live-gift-thanks-assistant/20260809_115929-d5b91d.png)

## 使用方法

1. **打开目标直播间。** 先登录用于场控的抖音账号，再进入需要管理的网页直播间。
2. **填写房间号。** 在插件控制台输入直播间房间号并保存，确认控制台显示正在运行，并且能收到该房间的礼物事件。
3. **设置规则和话术。** 在“规则”和“话术”页面设置触发条件与感谢内容。先用简单、自然的短句，避免每条消息都完全相同。
4. **先开礼物列表。** 只开启“礼物列表浮窗”，观察礼物事件能否被正确识别。
5. **再开自动感谢。** 确认识别正常后开启“自动感谢”，用小号送一笔低价值礼物完成测试。
6. **检查失败统计。** 若“发送失败”持续增加，先关闭自动感谢，再检查登录状态、房间号、连接状态和发送频率。

::: tip 推荐的上线顺序
先监听、不发送；确认礼物识别正确后，再开启低频感谢。不要在正式直播中直接测试未经检查的话术或高频规则。
:::

## 常见问题

### 安装后看不到插件图标怎么办？

在浏览器工具栏的“扩展”菜单中找到插件并固定。如果扩展列表也没有它，回到扩展管理页重新选择 `chrome-mv3` 文件夹。

### 为什么显示未连接？

先确认已经打开抖音网页直播间、房间号填写正确，并且运行 `install-host.bat` 后完整重启过浏览器。仍无法连接时，查看插件“日志”页面，不要反复开关自动发送。

### 自动感谢没有发送怎么办？

依次检查直播账号是否登录、自动感谢开关是否开启、规则是否命中，以及控制台中的“发送失败”是否增长。频繁失败时应暂停功能，避免连续重试触发平台风控。

### 可以在主账号上直接使用吗？

不建议。第三方侧载扩展会读取直播间页面并执行自动操作，实际权限、数据处理方式和平台兼容性都需要开发者说明。先用非主力账号、小流量直播间和低频规则验证更稳妥。

### 这是抖音官方工具吗？

不是。现有页面和截图只能证明这是面向抖音网页直播场景的第三方工具，不能证明它获得抖音官方认证或推荐。使用前请阅读[抖音开放平台处罚规则](https://open.douyin.com/platform/resource/docs/operation-standard/punish-standard/)及直播间现行规则，自动化操作是否可用应以平台最新要求为准。

## 是否值得使用？

如果你的直播间礼物消息较多，人工记录和逐条感谢已经明显影响直播节奏，这类工具确实能减少重复操作；控制台、礼物列表、失败计数和独立开关也让运行状态比较直观。

但它的安装链路比商店扩展更敏感，还涉及自动发送消息和第三方授权。建议先买最短周期，用非主力账号完成“安装、监听、单次感谢、失败处理”四项测试；只有在文件来源、账号表现和话术效果都能接受时，再考虑长期授权。
