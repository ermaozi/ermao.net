## Emby安卓TV使用教程

![Emby安卓TV使用教程 =1088x620](https://image.ermao.net/images/article/d3apexwx/image.png)

点击`跳过并输入IP地址`

![Emby安卓TV使用教程 =1088x620](https://image.ermao.net/images/article/d3apexwx/image-1.png)

输入服务器管理员提供的 IP 地址或域名、协议和实际端口，然后点击`确定`。不要只根据 `http` 或 `https` 猜端口：

* Emby Server 默认 HTTP 端口是 `8096`；已配置 HTTPS 时，默认 HTTPS 端口是 `8920`。管理员可以更改端口。
* 通过反向代理访问时，可能使用 `80` 或 `443`，也可能使用其他端口；以管理员提供的完整地址为准，不要把 `8096` 自动替换为 `80`，或把 `8920` 自动替换为 `443`。
* 自建服务器可从 Emby 控制台核对局域网和远程访问地址；受邀用户向管理员确认，不要擅自修改服务器或路由器设置。HTTPS 证书报错时先核对域名和证书，不要关闭证书验证。

端口与连接方式见 [Emby 官方客户端连接文档](https://emby.media/support/articles/Connectivity.html)。
